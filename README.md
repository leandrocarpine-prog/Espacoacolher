# Espaço Acolher

Site de captação para atendimento psicológico social em Rio Claro e região, com opção online.

## Privacidade
Esta versão não armazena respostas do formulário em banco de dados. Após a pré-triagem, o visitante pode encaminhar os dados diretamente ao WhatsApp profissional.

## Publicação
Compatível com GitHub Pages.
